# ArtiSys ERP

ERP desktop local-first e independente da ArtiSys. O núcleo obrigatório funciona localmente, sem serviço pago ou SaaS necessário para inicialização e operação.

O produto possui runtime, banco, autenticação, API, desktop e empacotamento próprios. Recursos exclusivos do PDV ArtiSys não fazem parte deste repositório.
