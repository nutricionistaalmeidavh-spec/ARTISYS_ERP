ERP ARTISYS — FUNCIONALIDADES ESPERADAS
Data: 25/09/2026

OBJETIVO
Construir um ERP modular para PMEs brasileiras, com core obrigatório gratuito, self-hosted e open source. Serviços pagos podem existir apenas como integrações opcionais, nunca como dependências do funcionamento principal.

- Auditoria completa de ações
- Histórico de alterações

- Sessões e controle de dispositivos
- Configurações gerais por empresa

==================================================
28. REGRA DE PRODUTO
==================================================
O funcionamento básico do ERP não pode depender de:
- assinatura SaaS obrigatória;
- banco de dados pago;
- storage pago;
- serviço de autenticação pago;
- gateway pago;
- API de IA;
- serviço de automação pago;
- serviço fiscal terceirizado obrigatório.

Esses recursos podem existir apenas como integrações opcionais.
